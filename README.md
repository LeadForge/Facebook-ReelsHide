# Hide Facebook Reels Chrome Extension

A simple Chrome extension that automatically hides **Facebook Reels** and short videos from your feed.

## 🔍 Why Use This?

Facebook Reels are designed to grab your attention and keep you scrolling. If you're looking to declutter your feed and regain control of your focus, this extension is for you.

## ✅ Features

- Automatically removes Reels from Facebook
- Lightweight and privacy-friendly (no data collection)
- Easy to install and use — no configuration needed

### Manual Installation

1. Download the latest `.zip` from [Releases](https://github.com/your-username/hide-facebook-reels/releases).
2. Unzip it.
3. Go to `chrome://extensions/`
4. Enable **Developer Mode**.
5. Click **Load unpacked** and select the unzipped folder.

## 🛠 How It Works

The extension uses content scripts to hide common selectors related to Reels on Facebook. It also runs periodically to catch dynamically loaded content.

## 📜 Permissions

This extension only requests access to Facebook pages. It does **not** collect or transmit any user data.
